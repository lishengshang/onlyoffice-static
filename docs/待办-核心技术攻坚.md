## A. 引擎侧黑盒（优先级最高）

### A1. 字体表竞态（引擎级缺陷）🔶

- **现象**：嵌套 iframe + 冷缓存时，url 文档转换与字体表填充赛跑，`fetchFonts` 内
  `AscFonts.g_font_infos` undefined 报 forEach TypeError。
- **已实证的根因链**：编辑器同时加载 sdk-all-min.js（2MB，无字体填充代码）与 sdk-all.js
  （14MB 完整版，含 `n()` 填充：从 AllFonts.js 的 `__fonts_files/__fonts_infos` 构建
  `g_font_infos/g_font_files`，执行完才删 `__fonts_files`）；url 转换由 app 启动即触发
  （x2t wasm 编译后调 fetchFonts）；完整版慢半拍时转换先赢。
- **现状**：壳层已做缓解——EmbedView 挂载即预热引擎大资源（`warmEngineResources`），
  创建编辑器前等预热完成，等效"二次访问"，竞态窗口闭合（embed 冒烟 11/11 冷缓存直开验证）。
- **攻坚路径**（彻底解决在引擎侧）：
  - ⬜ 自建引擎构建管线：基于 cryptpad/onlyoffice-x2t-wasm（活跃维护，2026-04 构建过
    v9.3.0.140）或官方 onlyoffice-x2t 分支，把字体表填充前移到转换之前；
  - ⬜ 或最小侵入 patch：在 min 版中补入 `n()` 填充代码段，消除双文件赛跑；
  - ⬜ 构建脚本可参考上游 issue #4（fernfei 称后续开源、至今未开源；与 cryptpad 构建不是同一产物）。

### A2. x2t_helper.js 文件流协议（逆向产物）⬜

- **现状**：保存链路依赖引擎内部脚本的两个私有行为——`window.OO_FILE_STREAM_ONLY`
  标志沿父窗口链检查（命中则只回传流不弹下载）；文件流消息不带 requestId
  （壳层用单槽 pending 匹配 + 自动保存静默持久化兜底）。
- **风险**：无官方文档背书，上游引擎升级可能悄悄改变行为，且**难以从外部发现**。
- **攻坚路径**：
  - ⬜ 建立引擎升级回归清单：以 shell/tests/ 三条冒烟为基线，每次换引擎必跑；
  - ⬜ 反编译阅读当前引擎的 x2t_helper.js 源码，输出协议文档（消息字段、父窗口链查找逻辑、
    失败路径），沉淀到 docs/；
  - ⬜ 单槽匹配的固有竞态（自动保存流可能被误配给进行中的手动请求）加版本/时序兜底。

### A3. DocsAPI 事件数据形状（实证拼凑）🔶

- **现状**：已用官方 web-apps api.js 源码 + 官方文档核对完壳层用到的全部 9 个事件，
  形状对照与判定固化在 **docs/参考-DocsAPI事件形状.md**（含 onError 结构化改进，已落地）。
- **攻坚路径**：
  - ✅ 对照官方源码/文档，把猜测固化为参考文档（2026-09-04 完成）；
  - ⬜ events 回调入口统一做 shape 收窄 + 未知形状的 console.warn，便于升级后第一时间发现漂移。

## B. 工程侧欠账

### B1. 引擎升级流程 ⬜

- `__ENGINE_VENDOR__` 自动扫描解决了**引用**问题，但新引擎目录拷入后的行为回归全靠人工冒烟。
- **攻坚路径**：升级 SOP 文档（拷贝规则 v1-strip-help、x2t.wasm.br 入库约束、AllFonts/版本串核对点）+ CI 增加 embed 冒烟（需 GitHub Actions 无头浏览器， play­wright 安装进 devDeps 的取舍待定）。

### B2. CI 覆盖面 🔶

- 已有：typecheck / lint / **vitest 单测（已进 CI）** / build；本地另有冒烟×3。
- 缺：E2E（冒烟脚本已入库 shell/tests/，但 playwright 未进 devDeps，CI 不跑）。
- **攻坚路径**：评估 `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` + `npx playwright install chromium` 的 CI 成本；或接受本地跑冒烟的现状，仅把单测加进 CI。

### B3. 安全面收口 ⬜

- `postToParent` 使用 `'*'` targetOrigin、入站消息不校验来源 origin——当前为兼容性妥协。
- **攻坚路径**：/embed 支持 `?allowOrigin=` 参数声明宿主白名单，默认收紧、显式放开。

## C. 部署侧

### C1. CF Pages 上线 ⬜（决策：等平台成熟）
